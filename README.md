# Infinity

Infinity ist eine Web- und Android-App für den Arbeitsalltag im Handwerk. Sie bündelt Kundenverwaltung, Auftragsplanung, Arbeitszeiterfassung, Materialverwaltung und Abrechnung.

Für Screenshots, Beispiele und Testdaten bitte ausschließlich fiktive Daten verwenden. Lokale Konfiguration und Zugangsdaten gehören außerhalb des Repositorys. Die Datei `.env.example` zeigt die verfügbaren Einstellungen.
